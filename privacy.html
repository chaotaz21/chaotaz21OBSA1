Privacy Policy

ObsidianSync is a personal OAuth configuration used to authorize the GSync plugin to access Google Drive for synchronizing Obsidian notes.

Data usage

Google Drive access is used for synchronizing files between my own devices.

Data storage

This website does not collect or store user data. Notes are stored locally and in the authorized Google Drive account.

Data sharing

This website does not sell or share user data.

Access revocation

Google Drive access can be revoked through Google Account security settings.
